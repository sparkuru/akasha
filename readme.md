# Akasha（アカシャ／虚空智慧之网）

>   fully vibe coding repo. thanks to trellis、claude code and codex.

一套配置/接口，按 `type` 把请求路由到不同后端引擎，统一浏览、取用、并把看到的目录落盘成索引。

「单一入口接通多个彼此独立的存储世界，并记录所见」。

出处：原神「虚空系统 / 智慧宫（Akasha）」，更早源自神智学的「阿卡夏记录」，即一座连接并收录一切知识的网络，由终端发起查询、自动从各处取回。意象对应能力：

| 项目机制 | Akasha 意象 |
|---|---|
| 一个入口、多后端 | 虚空终端接入整张知识之网 |
| `type` 路由到引擎 | 查询自动分发到对应知识源 |
| `index_store` 落盘目录快照 | 阿卡夏记录「收录所见」 |
| 引擎可注册扩展 | 网络可接入新的知识节点 |

包名/CLI 名：`akasha`。直接 `akasha ls tos:root/`、`akasha browse` 读感顺，且和「检索/索引」的功能语义自洽。

## 备选两个

- **Index（禁书目录）**：出自《某科学的禁书目录》，收录十万魔导书的少女即「Index」。优点是双关——项目本就有 index 功能；缺点是作为包名太通用、易撞名。
- **Yggdrasil（世界树）**：`.hack` 系世界树意象，一株主干连通多个世界，对「一套接口连多后端」也贴。但偏宏大、和「索引」这层弱。

三者里 **Akasha** 同时命中「统一入口 + type 分发 + 索引落盘」三层，契合度最高。
